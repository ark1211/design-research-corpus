# [VA-001] Suggestion chips must be action verbs anchored to user intent, not topic labels

## Rule

Suggestion chips displayed in a virtual assistant must be phrased as **action verbs anchored to user intent**, not as topic labels or noun phrases. Every chip must complete the implicit user question "I want to…" — e.g., "Track my order," "Find the best laptop for me," "Get technical support." Chips that name topics ("Orders," "Laptops," "Support") without action framing must not be used as primary conversational entry points, because they force the user to guess what will happen when tapped and shift the burden of task articulation from the assistant to the user.

## Scope

**Applies to:** All virtual assistant surfaces where suggestion chips are used to bootstrap or continue conversations, across authenticated consumer, SMB, commercial, and enterprise contexts. Includes initial-state chips (shown before the user has typed anything), follow-up chips (shown as replies to VA responses), and re-engagement chips (shown when a conversation has stalled).

**Does not apply to:** Navigation chips within a canvas (which are structural, not conversational). Filter chips in a list or search UI (which modify state, not initiate intent). Category cards on a landing page (different pattern, different research). Voice-first VA surfaces where chips may not be visible.

## Evidence

Action-verb chips outperform topic-label chips on every meaningful conversational metric: task initiation rate, task completion rate, user-reported clarity, and reduction in "what does this do?" clarifying questions. The reason is cognitive: users approach a VA with an intent ("I need to renew my subscription") but often don't know how the VA has scoped its capabilities. A topic label like "Subscriptions" requires the user to hypothesize whether their intent is covered. An action-verb chip like "Renew my subscription" *confirms* it before the user commits attention.

Nielsen Norman Group's research on conversational interfaces identifies the "guess the vocabulary" problem as the single biggest source of abandonment in early conversational UIs. Users abandon not because the VA couldn't help, but because they couldn't tell whether it could help without investing effort to find out. Action-verb chips solve this: the chip *is* the vocabulary, matched to intent.

Google's People + AI Guidebook (PAIR) explicitly recommends that suggested inputs be "written as complete user intents in first-person or imperative form" — the reasoning being that this reduces the calibration burden between the user's mental model and the system's capabilities.
